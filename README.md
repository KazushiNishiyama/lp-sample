# 3D & MUSIC JAM AI提案制作

就労継続支援B型事業所「3D & MUSIC JAM」に対して、AIを利用者の創作活動と集客導線に取り入れる提案一式です。

## 成果物

- `deliverables/3d-music-jam-ai-creative-pitch.pptx`  
  提案プレゼン資料。現行サイトの強み、AI活動メニュー、LP改善、広告バナー、30/60/90日導入計画をまとめています。
- `lp/index.html`  
  新LPの静的プロトタイプ。ブラウザで直接開けます。
- `banners/`  
  広告バナーのSVG原稿とPNG書き出し用スクリプトです。

## 情報源

- 現行サイト: https://musicjam.jp/
- 厚生労働省「平均工賃（賃金）月額の実績について」: https://www.mhlw.go.jp/stf/newpage_41739.html

## 提案の軸

「AIを使える事業所」ではなく、「利用者の好きな制作を、安全に、見学・体験・受注につながる成果物へ変える事業所」として見せる構成にしています。
